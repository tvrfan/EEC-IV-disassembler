
Development versions information.


This development subdir contains the latest test versions.  These should be stable to use, but probably have bugs, and may crash.

Windows builds (32 bit, built with CodeLite/Mingw) in Win32,  Linux builds (64 bit, built with Codelite/gcc) in Linux64.


"Versions.txt" lists changes between dev versions.
